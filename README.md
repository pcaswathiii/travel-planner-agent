# Multi-Agent Travel Planner

A multi-agent AI system built with CrewAI and Groq that plans a trip and checks it against a budget.

## How it works

Two agents work in sequence:

1. **Travel Planner**: creates a day-wise itinerary from the destination, duration, number of travelers, and interests.
2. **Budget Advisor**: takes that itinerary, estimates costs by category, compares them with the budget, and suggests cheaper alternatives if the budget is exceeded.

The second agent receives the first agent's output as context, so the budget is based on the actual itinerary.

## Example

Request: 3 days in Goa, 2 travelers, Rs. 15,000 budget.
The notebook output shows the generated itinerary and budget breakdown.

## Tech stack

- Python
- CrewAI
- Groq (LLM API)
- python-dotenv

## Setup

1. Install the libraries:

        pip install -r requirements.txt

2. Copy `.env.example` to a new file named `.env` and add your own Groq API key:

        GROQ_API_KEY=your_key_here

3. Open the notebook in Jupyter and run all cells.

## Limitations

- Prices and costs are estimates generated by the model, not live prices. The agents have no web search or pricing tools yet.
- Next step: add tools for real-time data such as web search or pricing APIs.
